# 🎲 Dicee — Dice Game

An interactive dice game built with HTML, CSS, and JavaScript. This project demonstrates DOM manipulation and JavaScript-based game interactions.

## ✨ Features

* 🎲 Dice images and visual results
* ⚡ JavaScript-powered interactions
* 🎨 Custom styling with CSS
* 🌐 Runs directly in a web browser

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 📁 Project Structure

```text
Dicee/
├── images/
├── dicee.html
├── index.js
└── styles.css
```

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/baraah29/Dicee.git
   ```

2. Open the project folder.

3. Open `dicee.html` in your browser.

4. Interact with the game to explore its functionality.
